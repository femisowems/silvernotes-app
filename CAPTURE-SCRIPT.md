# SilverNotes — Guided Capture Script (visual audit, Variation A)

One continuous Loom recording, silent is fine — the frames are what's
graded. Go slow: **pause ~2 seconds at every numbered stop** so each
state lands on clean frames. If a step doesn't work, don't stop —
keep recording; the failure is data too. Total: ~3–4 minutes.

## Prep (before you hit record)

1. SilverNotes **v0.7.2** installed (Settings → Check for Updates).
2. Settings → Appearance: density **Standard**, width **Standard**.
   Panel side: right. macOS appearance: **Light**.
3. Have a Finder window open behind the panel with **one image file**
   visible (for the drag beat — optional, skip if awkward).
4. Panel closed, desktop visible.

## The take

1. **Sliver** — desktop only, panel closed. Pause on the edge tab.
2. **Slide-in** — open the panel with **⌃⌥⌘Space**.
3. **Folders home** — pause on the folder list.
4. **All Notes (Standard)** — open it, pause. *(This is also v0.5.1
   check 36: cards with text + footers, correct bottom-bar count.)*
5. **Scroll** — slowly to the bottom of the list, then back to the top.
6. **Gear menu** — open it on the first card, pause, then close it.
7. **Fold** — fold a note (gear → Fold), pause, unfold it.
8. **Formatting toolbar** — click into the Welcome note, drag-select a
   sentence, pause with the toolbar showing, then Esc.
9. **Aa popover** — open it on any card, pause, close it.
10. **Drag-in** *(optional)* — drag the image from Finder onto the
    panel, pause on the drop highlight, drop it.
11. **Empty state** — Back → open the empty "Testing..." folder, pause.
12. **Trash** — Back → Trash, pause.
13. **Search** — open search, type `welcome`, pause on the results,
    then clear and close search.
14. **Settings** — open via the bottom-bar gear: General pane, pause;
    Appearance pane, pause; close Settings.
15. **Compact + expand** — Settings → Appearance → density Compact;
    All Notes; the list should open with **every note already
    expanded** into its full card — pause on that. *(The
    everything-expanded default, corrected in v0.6.2.)* Then **double-click the "Welcome
    to SilverNotes" row** so it expands into its card, pause.
    *(v0.5.1 check 38.)* Then set density back to Standard.
16. **Keyboard** — close the panel, reopen with ⌃⌥⌘Space, and press
    **Esc without clicking anything**. *(v0.5.1 check 37.)*
    Stop the recording.

## Part 2 — dark mode (separate short recording, whenever)

1. Start in **Light**. Open the panel with ⌃⌥⌘Space and go to the
   **Folders home** — leave the panel open for the next step.
2. macOS appearance → **Dark** (Control Centre) *while the panel
   stays open*. Pause on the folder home: names should stay
   readable — dark cards, light text, nothing white-on-white.
   *(The v0.7.1 flip check — the panel must follow the system
   without being reopened.)*
3. Click into All Notes (Standard), pause; scroll once; open the
   gear menu on the first card, pause.
4. Switch appearance back to **Light**, still with the panel open,
   and pause — surfaces should follow back.
5. Stop.

## Part 3 — the v0.7.2 surfaces (same session, ~1 minute)

1. **Gear-menu dismiss** — open any note's gear menu, then click a
   different note in the panel: the menu should close and the
   click should do nothing else.
2. **Checklist editing** — create a Checklist Note (+ menu), type
   a task, press Enter (a fresh task starts), use **+ Add item**
   once, then fold the note from its gear menu: the folded title
   should read your task text (or "Checklist · 0 of 3 done").
3. **Trash rows** — trash any note, open Trash: full-width rows
   with the deleted date and Restore / Delete Forever; tap
   Restore and confirm the note is back.

## What this covers

Rubric states A1–A9, A11–A15 (A10 first-run welcome is prose-only in
the mockup and can't be captured without a fresh store), v0.5.1
confirmation checks 36–38, the all-expanded default in every
density (beat 15), and the v0.7.2 checks 39–43 (Part 3).
